# Perfect Rules

阿尔忒弥斯实验室（Artemis Lab）整理和维护的代理软件完美分流配置文件。

本项目包含不同代理软件的完美分流配置文件，均经过整理和测试。下载对应的配置文件后，可以直接导入代理软件使用；同时也可以根据自己的实际需求，在代理软件的 UI（图形化）设置页面中进行进一步的调整和自定义。

相关的详细教程，请访问阿尔忒弥斯实验室 YouTube 频道。

选择对应代理软件的配置文件，下载后可以直接导入使用。
